# Suman Debnath: Career Mode

A one-page résumé you walk through as a small pixel-art game. Live at https://hire.sumandebnath.houseofnamus.com/ (hosted on Vercel as a static site; there is no build step).

- `index.html`, `styles.css`, `ui.css`, `js/`: the live page. Every sprite is drawn in code; the only image files are `og-image.png` and the icons.
- `classic/`: a backup of the previous version of the page. It is marked `noindex`.
- `llms.txt`, `robots.txt`, `sitemap.xml`: for search engines and AI assistants.

To run it locally, serve the folder with any static server, for example `python -m http.server 5186`, and open http://127.0.0.1:5186/.
